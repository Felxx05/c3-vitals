# FM Vitals

Begleit-App zum FM 112 Simulator für iPhone und iPad (Hochformat):
Blutzucker-Messgerät (mmol/l), Ohrthermometer, Auskultation (Lunge, Herz, Bauch) und BOSS-Melder.

**Öffnen:** https://felxx05.github.io/c3-vitals/

Koppeln: Am Monitor „Geräte koppeln“ → „FM Vitals“ → QR-Code scannen.
Danach in Safari „Teilen → Zum Home-Bildschirm“, damit die App im Vollbild läuft.
Werte, Geräusche und Einsatzmeldungen kommen von der Steuerkonsole (Knopf „FM Vitals“).
